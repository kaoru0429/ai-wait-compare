# AI 等待時間比較

手機友善的單頁網頁，用來比較不同 AI 模型「開始輸出前的等待」與「實際輸出時間」，並依**最早完成**排序。

## 為何需要這個工具？

許多人只看 tokens／秒（tok/s）。但若某個模型要等很久才開始輸出，即使輸出很快，**總完成時間仍可能輸給「稍慢、但很快開始」的模型**。本頁把兩段時間分開顯示，讓差異一眼可見。

## 計算公式

```
總秒數 = 等待秒數 + (希望產生 tokens ÷ 每秒輸出 tokens)
```

- **等待秒數**：從送出請求到模型開始吐出第一個 token 的時間  
- **實際輸出時間**：希望產生的 tokens ÷ 每秒輸出 tokens  
- **總完成時間**：兩者相加（越小越早完成）

## 使用方式

1. 用瀏覽器開啟 `index.html`（無需伺服器）
2. 在表單填入：模型名稱、開始輸出前等待秒數、每秒輸出 tokens、希望產生 tokens
3. 列表會自動依總時間由短到長排序，並顯示名次
4. 長條圖以堆疊方式顯示「等待」與「輸出」兩段時間
5. 可編輯、刪除模型；資料存在瀏覽器 `localStorage`（鍵名：`ai-wait-compare-v1`）
6. 「還原示範資料」可重新載入虛構範例；「清空全部」會刪光本機資料

## 虛構示範資料（非真實模型）

頁面頂部有明顯橫幅標示資料為**虛構範例**。預設三筆：

| 模型名稱 | 等待 | tok/s | 希望 tokens | 輸出時間 | 總時間 | 名次 |
|---|---:|---:|---:|---:|---:|---:|
| 虛構範例・短等待慢輸出 | 10 秒 | 30 | 900 | 30 秒 | **40 秒** | 1 |
| 虛構範例・中等均衡 | 25 秒 | 45 | 900 | 20 秒 | **45 秒** | 2 |
| 虛構範例・長等待快輸出 | 45 秒 | 150 | 900 | 6 秒 | **51 秒** | 3 |

重點洞察：第三筆的 tok/s 最高（150），但因等待過長，**反而最晚完成**——比「較慢輸出、較短等待」的第一筆晚約 11 秒。

## 技術說明

- 單一檔案：`index.html`（內嵌 CSS／JS）
- 圖表：Chart.js（CDN）
- 無登入、無後端、無外部模型 API
- 介面：繁體中文、行動優先（約 390px 寬可用）

## 本機開啟

```bash
# 直接用瀏覽器開啟檔案
xdg-open index.html   # Linux
open index.html       # macOS
# 或雙擊 index.html
```

亦可在專案目錄啟動簡易靜態伺服器後以 `http://localhost:...` 開啟。
